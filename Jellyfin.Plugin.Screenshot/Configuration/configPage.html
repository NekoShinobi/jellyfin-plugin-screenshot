Screenshot Capture

Adds a photo_camera button to the video player OSD. Clicking it lets you capture with the currently selected subtitles or without subtitles. The Jellyfin server extracts the exact frame via FFmpeg and returns it as a JPEG download.

The scissors button opens the Focus clip editor. Select up to 60 seconds before and after the current moment, preview the selection, and download an MP4 with the selected audio and optional subtitles. The preview fits the video in a 16:9 box; downloaded clips preserve the source aspect ratio.

Clipping requires permission to play and download the video. No configuration required.
